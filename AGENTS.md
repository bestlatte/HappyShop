# AI Workflow Policy

For small fixes or simple code changes:
- Do not use heavy Superpowers workflows.
- Do not use subagents, parallel agents, or git worktrees unless explicitly requested.
- Make surgical changes only.
- Explain what changed and how to verify it.

For larger features:
- Ask before using brainstorming, writing-plans, TDD, worktrees, or subagents.
- Do not start implementation until the plan is approved.
